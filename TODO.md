# Parked ideas

Small things worth doing that aren't scheduled. Bigger direction lives in
[ROADMAP.md](./ROADMAP.md), and anything a team member files inside the app lands on
the Features board (`/features`).

- **Richer artifact hosting** — serve a multi-file, bundled app from storage behind the
  same public page URL, so a generated SPA can be shared like an HTML artifact is today.
- **Image generation** — let the assistant generate images through OpenRouter and save
  them straight into Files.
- **Reindex on demand** — a button (and a tool) to re-run knowledge indexing for a
  document after a failed or partial extraction.
- **Release marker in the footer** — show the deployed commit so it's obvious which
  build a workspace is running.
- **More forged function examples** — a calculator, an OCR-before-AI PDF parser, a
  page-to-markdown fetcher. Each is a small deterministic step other automations can
  call, and they double as Forge documentation.
